# Swiss Snow Rush ❄️

A minimalist, Christmas-inspired travel website for **Swiss Snow Rush – 12 Days of Winter Fun**, a proposed winter trip through the Bernese Alps in Switzerland.

## Website sections

- Trip overview
- Estimated budget per person (MXN $68,000)
- Expandable 12-day itinerary with schedules, transport and locations
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub, for example `swiss-snow-rush`.
2. Upload `index.html` and this `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Notes

- The page uses externally hosted Unsplash images, so an internet connection is needed to load them.
- Dates, schedules, flight details and prices are proposed estimates from the project brief and should be confirmed before booking.
- This is a static HTML website; it does not require a build step, Node.js or a framework.
